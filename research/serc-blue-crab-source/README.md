## Interpretation

3,346 occurrence records represent 35 tagged animals: 35 releases and 3,311 summarized acoustic detections. Join occurrence.eventID to event.eventID. Parent events are not independent animal detections. Receiver coordinates are not a continuously observed animal trajectory; the interface deliberately does not connect gaps. Counts of hourly summaries are neither ping counts nor abundance estimates. Missing uncertainty is not zero. Source timestamps remain visible verbatim; timestamps without a timezone use UTC only for consistent plotting. No depth is inferred.

The extendedmeasurementorfact table is not consumed: its apparent header/data column alignment needs independent resolution before using its measurements.
