# Messenger adaptation — site 02

The Lando homepage, centered globe, parallax, calendar, collection, dialogs and Archive remain in place. Messenger adds an optional Field Explorer launched with “Step inside the world.”

## Source-to-adaptation map

| Catalogue | Labyrinth implementation |
| --- | --- |
| MS-A01 staged entrance | Animated world arrival, dimensional title and Begin action |
| MS-A02 ambient fragments | Animated floating fragments with reduced-motion support |
| MS-N01 single entry action | Begin exploring; optional rather than a site-wide gate |
| MS-N02 character navigation | Arrow/A-D walking, drag rotation, direct destination travel |
| MS-V01 illustrated tiny planet | Original shaded SVG world with layered landmarks, guides, terrain and route |
| MS-V02 teal/cream palette | Dark forest/teal stage, cream text, botanical lime and warm accents |
| MS-L01 spacious scene | Centered world with peripheral navigation and contextual conversation |
| MS-I01 NPC interactions | Four fictional guide roles with links to existing records and marketplace |
| MS-I02 configuration | Explorer color and hat settings, saved locally |
| MS-M01 rendered world | SVG-based depth-sorted illustration, not a copied WebGL engine |

Additional local features: day/night appearance, discovered-place indicators, return-to-start, optional synthesized arrival chimes, direct keyboard-accessible landmark selection, native modal close/Escape behavior.

## Evidence limits

Live Messenger intro visually inspected this turn. Its Begin action remains blocked by the browser's closed-shadow-root interaction limitation; the earlier catalogue explicitly marks its in-world navigation, NPC and configuration references as award-described. Do not represent these as newly tested live-source behaviors. Audio is an original local addition, not verified source audio. The adaptation covers the saved catalogue categories, not a claim that every feature of the source game has been exhaustively reproduced.
